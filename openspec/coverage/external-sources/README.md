# Frozen external descriptor cache

These files are documentation inputs for offline reference checks. The registry binds each cached file to its repository, commit, repository path, Git blob ID and SHA-256. Its source-record pointer names the provenance already declared in the aggregate ledger. The checker reads cached bytes and never follows the recorded retrieval URLs.

The SOPS 3.13.3 files are stored byte-for-byte with inert .blob suffixes. The upstream MPL 2.0 license is preserved alongside them. These files are outside the production dependency graph. [Official upstream source and license](https://github.com/getsops/sops/tree/26e2f4784ca61353082c32dbd987c25eda086dc9)
